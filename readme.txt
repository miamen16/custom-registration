A lightweight WordPress registration form built from scratch without third-party plugins.

== Description ==

Custom Registration provides a shortcode-based registration form using native WordPress APIs.

== Installation ==

1. Upload the plugin to /wp-content/plugins/custom-registration/.
2. Activate the plugin.
3. Create a page and add [custom_register_form].
4. Publish the page.
